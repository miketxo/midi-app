Protocol / Protocolo
Manufacturer: 40h (Kawai)
Machine: 0Ah (K5000)
BLOCK REQ: F0 40 ch 01 00 0A 00 <bank> 00 F7
BLOCK DUMP: F0 40 ch 21 00 0A 00 <bank> [map] [data] F7
ONE REQ: F0 40 ch 00 00 0A 00 <bank> <n> F7
ONE DUMP: F0 40 ch 20 00 0A 00 <bank> <n> [data] F7
Checksum: (Σ data + 0xA5) & 0x7F
Name offset: DATA[40..47] (8 ASCII chars)
Bank IDs / IDs de Bancos
Bank A (ADD, ≤120): 00h
Bank E (ME-1 ADD): 03h ← ME-1 required
Bank F (ME-1 ADD): 04h ← ME-1 required
Combi C1–C64: 20h ← ONE bank only
Multi Banks B/E/F: not on K5000W

About
K5000W MIDI Driver v1.1 — part of Synth MIDI Manager.
Web MIDI API (Chrome/Edge + HTTPS required).
Roland UM-ONE MK2 compatible.
Based on K5000W/S/R MIDI Implementation v2.0.
↑ Import JSON / Importar
Paste the JSON exported from this driver, or select a file.
Note: this replaces the current bank data in memory. The synth is not affected until you press Restore.
↑ Restore Bank to K5000W
This will send all patches in the current bank back to the K5000W via SysEx ONE DUMP.
⚠ Make sure the K5000W is on and MIDI is connected.

Patches are sent one by one to their original slot numbers.
